# Внутри скобок

Самостоятельный интерактивный учебный мини-сайт по комплексным соединениям.

## Файлы
- `index.html` - страницы и содержание
- `styles.css` - оформление и адаптивная вёрстка
- `app.js` - поэтапная визуализация электронных пар, сборка комплексов, интерактивный тест, задания

Не использует сборщик, зависимости или сервер: достаточно открыть `index.html` в браузере. Данные тестирования не отправляются на сервер.

## Размещение
Все файлы находятся в `chemistry-complexes/` внутри репозитория `site_test`, чтобы не менять существующие проекты.

Если GitHub Pages в настройках репозитория уже публикуется из ветки `main`, директория станет доступна по адресу:
https://smirnovairina7090-blip.github.io/site_test/chemistry-complexes/

Если Pages не включён: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Содержание
Строение комплекса; донорно-акцепторный механизм; электронные пары NH₃, H₂O, OH⁻; расчёт заряда; комплексные катионы/анионы; координационные числа; устойчивость и кинетическая инертность; реакции алюминия, цинка, меди, серебра и кобальта; 20 заданий с автоматической проверкой.

## Ограничения моделей
Визуализации упрощены и не претендуют на точное моделирование электронной плотности или трёхмерной геометрии. Промежуточные результаты конструктора служат только арифметической иллюстрацией и могут не соответствовать реально устойчивым ионам. Используйте опасные соединения исключительно в теоретических заданиях.
