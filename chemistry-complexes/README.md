# Комплексные соединения - подготовка к ЕГЭ по химии

Самостоятельный интерактивный учебный сайт. Назначение: углублённая теория, разборы уравнений, лабораторные схемы и задачи для подготовки к ЕГЭ.

## Публичный сайт

https://chemistry-complexes-lab.vercel.app/

Публикация выполняется напрямую через Vercel. Настройки GitHub Pages в репозитории site_test для этой страницы не требуются.

## Содержание

1. Положение темы в подготовке к ЕГЭ (официальный навигатор ФИПИ).
2. Определение комплексного соединения, центр, лиганды, внутренняя и внешняя сферы.
3. Донорно-акцепторная связь, неподелённые электронные пары NH3, H2O и OH−.
4. Интерактивная сборка 8 комплексов.
5. Квадратные скобки, расчёт заряда и степени окисления.
6. Координационное число, пространственная геометрия и полидентатные лиганды.
7. Термодинамическая устойчивость и кинетическая инертность.
8. Реакции гидроксокомплексов алюминия и цинка, а также дополнительные амминокомплексы.
9. Модель недостатка и избытка NaOH.
10. Алгоритм решения ионных уравнений.
11. 14 задач с подробными решениями и короткие числовые проверки.
12. Контрольный тест из 26 вопросов с автоматической обратной связью.

## Файлы
- index.html - HTML и учебное содержание
- styles.css - адаптивное сдержанное оформление
- app.js - схемы, конструктор, проверка ответов

Без внешних зависимостей и без отправки результатов тестов на сервер.

## Официальные ориентиры
ФИПИ: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory

ФИПИ, навигатор ЕГЭ по неорганической химии: https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/hi-neorganicheskaja-himija.pdf

Приведённые упражнения являются авторскими заданиями на экзаменационные навыки и не выданы за реальные задания ФИПИ.

## Безопасность
Практические демонстрации с комплексами серебра, соединениями кобальта, цианидными комплексами и другими опасными веществами в материале не предполагаются.
