01

Переменные и именование

Переменная - имя, связанное со значением. Для обычных переменных используем понятные имена в стиле snake_case.

Присваивание

age = 14
student_name = "Маша"
is_ready = True

print(student_name)

= выполняет присваивание: сначала вычисляется правая часть, затем значение связывается с именем слева.

Проверка имени

Здесь проверяется не только синтаксис, но и стиль учебного кода.

Введите имя переменной.
Правила именования
Используем строчные латинские буквы a-z. Имя начинаем с буквы. Несколько слов разделяем _. Цифры допустимы после первой буквы. Не используем пробелы, дефисы, ключевые слова Python и имена встроенных функций вроде print, input, int, range.
Почему русские буквы и заглавные здесь не принимаются?
Python технически допускает Unicode и заглавные буквы в идентификаторах. В этом листе мы намеренно придерживаемся стиля обычных переменных: латиница, нижний регистр и snake_case. Примеры: student_name, item_count, max_speed.

03

input() и print()

input() всегда возвращает строку. Для вычислений ввод часто нужно преобразовать через int() или float().

Типичная ошибка

a = input()
b = input()
print(a + b)

Если ввести 2 и 3, получится 23, потому что складываются строки.

a = int(input())
b = int(input())
print(a + b)   # 5

Проверка ввода

Что произойдёт при int("кот")?
Возникнет ValueError: произвольный текст нельзя преобразовать в целое число. Строки "12" и "-8" преобразуются, а "2.5" для int() уже не подходит.
04

Операции

Сравни основные арифметические операции. Особенно важны // и % - они часто встречаются в задачах.

a17
b5

// - целочисленное деление

Показывает, сколько полных групп помещается.

17 // 5  # 3

% - остаток

Показывает, сколько останется после выделения полных групп.

17 % 5   # 2
Где полезен остаток?
Чётность: n % 2 == 0. Последняя цифра: n % 10. Позиция внутри группы и циклические переходы тоже часто строятся на %.
Приоритет операций
Скобки → ** → * / // % → + -. Если выражение сложное, ставь скобки явно.
05

Условия

if выбирает действие по условию, elif добавляет варианты, else обрабатывает оставшийся случай.

score = int(input())

if score >= 80:
    print("Высокий результат")
elif score >= 50:
    print("Зачёт")
else:
    print("Требуется повторение")

Симулятор условия

score63

and

Оба условия истинны.

age >= 12 and age < 18

or

Хотя бы одно истинно.

day == 6 or day == 7

not

Инвертирует логическое значение.

not is_ready
Не путай = и ==
= присваивает значение. == сравнивает два значения и возвращает True или False. После if, elif, else ставится двоеточие, а тело ветки записывается с отступом.
06

Циклы

for удобен для известного количества повторений. while повторяется, пока условие истинно.

for

for i in range(5):
    print(i)

Вывод: 0, 1, 2, 3, 4.

while

x = 3
while x > 0:
    print(x)
    x -= 1

Вывод: 3, 2, 1.

Визуализатор range(n)

n5

range(stop)

range(5)
0 1 2 3 4

range(start, stop)

range(2, 6)
2 3 4 5

range(start, stop, step)

range(2, 10, 2)
2 4 6 8
break, continue и бесконечный while
break завершает цикл. continue переходит к следующей итерации. В while значение, влияющее на условие, должно меняться, иначе цикл может стать бесконечным.

Практика

Проверка ищет ключевые конструкции решения. После неё всё равно запусти код и протестируй на нескольких входных данных.

1. Упаковка заказов

В переменной items количество товаров. В коробку помещается 4 товара. Выведи число полных коробок и остаток.

Нужны //, % и print().

2. Проверка допуска

Если возраст не меньше 12, выведи Допущен, иначе Не допущен.

Нужны if, else и >= 12.

3. Пять сообщений

С помощью for выведи слово Проверка ровно 5 раз.

Используй range(5).

4. Олимпиадная разминка

В одном ряду 8 мест, нумерация билетов начинается с 1. По номеру n найди номер ряда.

Ключевая формула: (n - 1) // 8 + 1.
