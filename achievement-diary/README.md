# Дневник достижений Креайтивики

Дневник ученика: https://smirnovairina7090-blip.github.io/site_test/achievement-diary/

Страница опубликована на GitHub Pages. При создании выдаёт личный логин и пароль. Вход, записи и прогресс сохраняются на сервере и доступны на другом устройстве. Компьютер становится цветным после восьми деталей; детали и пять наград открываются отдельными кодами преподавателя. Коды сохраняются у преподавателя и не публикуются в репозитории.

Страница работает без обращения браузера к домену ChatGPT. API сохранения: https://creitivika-diary-api-smirnovairina7090-8722s-projects.vercel.app/api/diary

Полный исходный код находится в ветке achievement-diary-accounts. Электронная версия не заменяет печатный дневник: diary-a4.pdf доступен для скачивания.
