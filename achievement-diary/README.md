# Дневник достижений Креайтивики

Первая версия дневника на 8 занятий для любых направлений школы.

Откройте index.html через статический сервер или GitHub Pages. Сборка и серверная база данных не требуются.

## Как использовать

1. Укажите ученика, направление, преподавателя и период.
2. После занятия нажмите на его номер или часть ракеты, выберите названный преподавателем цвет и запишите небольшой успех.
3. Отмечайте бинго вместе с преподавателем. Для центральной клетки впишите конкретный навык.
4. Преподаватель отмечает подходящие награды.
5. После восьми занятий заполните итог и следующую цель.
6. Через меню сохранения скачайте завершённый маршрут и начните новый.

## Печать

diary-a4.pdf - чистый одностраничный шаблон A4 для ручного заполнения.

Кнопка «Печать моего листа» печатает текущие отметки и цвета. Выберите A4, портретную ориентацию, масштаб 100%, без браузерных колонтитулов.

## Данные

Прогресс автоматически хранится только в текущем браузере через localStorage. Он не синхронизируется между учениками, преподавателем и разными устройствами. Для переноса предусмотрены экспорт и импорт JSON. Перед импортом, очисткой или новым маршрутом появляется подтверждение.

Логин и пароль Skillspace не сохраняются и не экспортируются. В печатном шаблоне предусмотрены пустые поля для заполнения ручкой.

Кнопка Skillspace сначала ведёт на официальный сайт сервиса. Преподаватель может добавить прямую ссылку своей школы или курса через «Указать ссылку школы».

## Награды и бонусы

Отметки в жизни школы включают олимпиаду, конкурс проектов и приглашённого друга, посетившего пробное занятие. Макет не обещает скидок, денежных вознаграждений или обмена баллов. Условия дополнительных бонусов школа может определить отдельно.

В раскраске цвет выбирается по решению преподавателя и ребёнка. Он не обозначает оценку или уровень успеваемости.
