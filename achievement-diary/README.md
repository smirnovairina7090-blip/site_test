# Дневник достижений Креайтивики

Технологичная версия дневника на 8 занятий. Подходит программированию, разработке игр, дизайну, математике и репетиторству.

## Как заполнять

1. Укажите ученика, направление, преподавателя и период.
2. После каждого урока преподаватель называет цвет. Нажмите на модуль платы с номером урока, выберите цвет, дату и запишите результат.
3. В бинго отмечайте конкретные выполненные действия. Три клетки в строке, столбце или по диагонали составляют линию бинго. В центре впишите освоенный учеником навык.
4. Преподаватель отмечает знаки отличия за сложное решение, собственную идею, самостоятельную работу и понятное объяснение.
5. После 8 занятий заполните результат и следующую цель. Через меню сохранения скачайте завершённый маршрут и откройте новый лист.

## Печатная версия

diary-a4.pdf - один цветной лист A4 для ручного заполнения.

Кнопка «Печать моего листа» печатает текущие отметки. Параметры: A4, портретная ориентация, 100%, без браузерных колонтитулов. Для сохранения оформления включите печать фоновой графики.

## Данные

Прогресс хранится в localStorage только в текущем браузере. Для другого устройства доступны экспорт и импорт JSON. Облачной синхронизации между учеником и преподавателем нет.

Логин и пароль Skillspace не сохраняются и не включаются в экспорт. На бумажном листе преподаватель заполняет эти поля ручкой. В онлайн-версии прямая ссылка на курс настраивается кнопкой «Указать ссылку школы».

При обновлении с первой версии записи занятий и личные поля переносятся. Бинго и награды заполняются по новым условиям. Прежние данные остаются под старым ключом localStorage.

## Оформление

Оригинальный инверсный логотип школы, Manrope, основные цвета #332e3b, #f9b233 и #6aa7dd. Все технологические иллюстрации, модули раскраски и награды выполнены в точной векторной графике.

Цвет модуля выбирается для раскраски и не обозначает оценку успеваемости. Участие в олимпиаде, конкурсе проектов и приглашение друга отмечаются отдельно. Конкретные скидки и обмен бонусных баллов этот макет не обещает.
