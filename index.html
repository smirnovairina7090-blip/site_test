01

Переменные

Переменная - это имя, под которым программа хранит значение. Представь подписанную коробку: имя снаружи, значение внутри.

Как это выглядит

age = 14 name = "Маша" is_ready = True print(name)

Знак = здесь означает присваивание: положить значение справа в переменную слева.

Проверка имени переменной

Введи имя и узнай, можно ли так назвать переменную.

Подсказка появится здесь.
Правила хорошего имени
Можно использовать буквы, цифры и знак подчёркивания _. Имя не должно начинаться с цифры. Пробелы запрещены. Нельзя использовать ключевые слова Python вроде if, for, while, True.
Какое имя лучше: x или student_score?
Если задача маленькая и смысл очевиден, x допустим. В реальной программе понятное имя вроде student_score почти всегда удобнее.

03

input() и print()

input() получает данные от пользователя. Важно: результат input() всегда строка, даже если человек ввёл цифры.

Классическая ловушка

a = input() b = input() print(a + b)

Если ввести 2 и 3, программа напечатает 23.

a = int(input()) b = int(input()) print(a + b)

Теперь получится число 5.

Попробуй сам

Результат появится здесь.
А что будет, если написать int("кот")?
Python получит ошибку ValueError: строку "кот" нельзя превратить в целое число.
04

Основные операции

Двигай числа и смотри, как меняются результаты. Особенно обрати внимание на // и %.

a17
b5

Целочисленное деление //

Показывает, сколько полных групп по b помещается в a.

17 // 5 → 3

Остаток %

Показывает, сколько останется после выделения всех полных групп.

17 % 5 → 2

Условия

if позволяет программе выбрать действие. elif добавляет вариант, else ловит всё остальное.

score = int(input()) if score >= 80: print("Отлично") elif score >= 50: print("Неплохо") else: print("Попробуй ещё")

06

Циклы

for удобен, когда понятно количество повторений. while работает, пока условие истинно.

for

for i in range(5): print(i)

Выведет: 0, 1, 2, 3, 4. Верхняя граница 5 не входит.

while

x = 3 while x > 0: print(x) x -= 1

Выведет: 3, 2, 1.
